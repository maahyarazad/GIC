# Implementation Plan: Event Card Layout & My Events

**Branch**: `002-events-my-events` | **Date**: 2026-10-06 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/002-events-my-events/spec.md`

## Summary

1. **My Events** — new first section in Dashboard → Events listing the signed-in user's registrations for GIC events, with a QR dialog. The GIC server proxies the services platform (`SERVICES_SERVER_ORIGIN_DEV` / `_PROD` by `NODE_ENV`) through a new `servicesServer` helper. The existing, unused `/my-events` endpoints are rewritten: auth via `authMiddleware`, identity from the user record, case-insensitive email match restricted to GIC event pages, constant upstream query params (fixes a SQL injection path), and an ownership-checked `GET /my-events/{reference}/qr` that streams the PNG (fixes a no-auth / path-traversal / broken-Buffer endpoint).
2. **Card layout** — card markup extracted to `EventCard.tsx`; every card is `aspect-ratio: 16/9`; the top-left date chip becomes a full-height calendar block on the left edge.

Verified live against the dev services server (see [research.md](./research.md)).

## Design Notes

### Server

- `servicesServer.ts`: `getServicesOrigin()` per `NODE_ENV`; `servicesFetch(path, query?)` builds the URL with `URLSearchParams`, signs `jwt.sign({}, EXTERNAL_ACCESS_SECRET, { expiresIn: tokenExpiry.externalAccess.value })`, `AbortSignal.timeout(10_000)`, returns the `Response`. Throws a typed `ServicesUnavailableError` on network/timeout.
- `getMyEvents`: resolve email (R2) → `Promise.all([config, registrations])` → filter + map + sort (data-model) → `{ items, total }`.
- `getMyEventQr(@Path() reference)`: validate → ownership lookup (R4) → `/api/qr` with `encodeURIComponent` values → `Readable.from(Buffer.from(await res.arrayBuffer()))` with headers from the contract.
- Shared `findUserEmail(req)` and `emailMatches(a, b)` helpers inside the controller file.

### UI

- `EventCard` props: `{ event, showUpcomingBadge?, onClick, footer? }`. Date block renders only when `toLocalDay(event.event_date)` is non-null; `toLocalDay` moves to `EventCard.tsx` and is exported for `splitEventsByDate`.
- `MyEvents` owns its fetch state (independent of the events fetch — FR-010). Footer: reference + optional payment chip + "Show QR" (`stopPropagation` not needed; the whole card opens the dialog).
- `MyEventQr`: `useEffect` fetch blob → object URL; cleanup revokes; 404 → "not available yet".
- SCSS: `.card { aspect-ratio: 16/9; }` (remove `min-height`), `.event-date-block` (left, full height, ~22% / min 64px), `.card-body.has-date { padding-left: <block width>; }`, title `clamp()` + 2-line clamp, `.my-event-footer` absolute bottom strip inside the card.

## Out of Scope / Follow-ups (services repo)

- `authorize_admin` accepts invalid `x-access-token` (R3/S5).
- `/api/qr` path traversal and `ORDER BY ${sortField}` injection should also be fixed server-side; this plan only removes the GIC paths that reach them.
