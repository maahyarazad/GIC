## Design decisions (see research.md)

- **Requests modal**: reuse `ModalDialog` with `content` = search field + `LetterRequestList`,
  `onCancel` = close. Opened by a "Requests" button in the `dash-header`. Selecting a row (or
  sending) closes the modal. The unsaved-changes `confirm()` in `select()` runs before switching.
- **Search**: client-side filter over the already-loaded `items` (no new request); case-insensitive
  substring match on `reference`, `requester.name`, `requester.email`, `requester.company`.
- **Live preview**: `LetterPreview` holds a blob-URL `<iframe>`. The editor calls a refresh callback
  on each field `onBlur`; the callback validates with the existing `previewSchema`, and on success
  POSTs the current values to the inline-PDF endpoint and swaps the iframe `src`. Invalid draft →
  show a short message in the pane (no popup, no tab). Refresh is debounced (~400 ms) and guarded so
  a field that blurs without changes doesn't re-fetch. Blob URLs are revoked on replace/unmount.
- **Actions at top**: move the `rl-editor__actions` block above the field groups; CSS drops the
  `border-top`/`margin-top` and adds bottom spacing instead. Same buttons, same handlers/busy states.
